วิธีทำให้เปิดไมค์ & คุยด้วยเสียงบนมือถือได้ 100%:

เนื่องจากเบราว์เซอร์บนมือถือ (Chrome/Safari) มีระบบความปลอดภัยสูง หากเข้าผ่าน HTTP ปกติจะปิดไมค์ ให้เลือก 1 ใน 2 วิธีนี้ค่ะ:

  • วิธีที่ 1 (แนะนำมากที่สุดสำหรับ Android Chrome): เข้าผ่านลิงก์ HTTP ปกติ ➔ เปิดแท็บใหม่พิมพ์ chrome://flags ➔ ค้นหา Insecure origins treated as secure ➔ ใส่ลิงก์ของ Friday ➔ เลือก Enabled แล้วกด Relaunch ไมค์และการคุยด้วยเสียงจะใช้งานได้เต็มระบบทันที!
  • วิธีที่ 2 (เข้าผ่าน HTTPS): เลือกแท็บ HTTPS ด้านบน แล้วสแกนเข้าพอร์ต :8443 (หากขึ้นหน้าเตือน ให้กด ขั้นสูง/Advanced ➔ ไปยังเว็บไซต์) ไมค์จะเปิดได้ทันที

ขั้นตอนการใช้งานใน CapCut PC

  1. เมื่อกดปุ่ม "บันทึกลง CapCut PC ทันที" Friday จะสร้างโครงสร้างโปรเจกต์ draft_content.json ลงในโฟลเดอร์ Drafts ของเครื่องคุณ
  2. ระบบจะลงทะเบียนโปรเจกต์เข้าสู่ root_meta_info.json ของ CapCut อัตโนมัติ
  3. เมื่อคุณเปิดโปรแกรม CapCut PC จะพบโปรเจกต์นี้แสดงอยู่ในหน้าแรก (Projects) ทันที!
  4. สามารถเปิดคลิปเข้าไป ลากไฟล์วิดีโอ/ฟุตเทจเข้ามาวางทับซับไตเติลและเสียงพากย์ได้ทันที

ขั้นตอนการใช้งานใน Adobe Premiere Pro

  1. เมื่อกดปุ่ม "ส่งออก Premiere Pro" Friday จะสร้างไฟล์ .xml (Final Cut Pro Interchange), .jsx (ExtendScript) และ .srt (Subtitles)
  2. เปิดโปรแกรม Adobe Premiere Pro ขึ้นมา
  3. ไปที่เมนู File > Import... (หรือกด Ctrl + I) แล้วเลือกไฟล์ .xml ในโฟลเดอร์โปรเจกต์
  4. Sequence จะถูกสร้างขึ้นมาพร้อม Markers ทุกฉาก และไฟล์เสียงพากย์จะถูกวางลงใน Audio Track โดยอัตโนมัติ!

ขั้นตอนการใช้งานใน Alight Motion (มือถือ Android / iOS)

  1. เมื่อกดปุ่ม "ส่งออก Alight Motion (.xml)" Friday จะสร้างไฟล์ Project Package .xml พร้อม Typography, Velocity Scale และเสียงพากย์
  2. ดาวน์โหลดไฟล์ .xml โดยกดปุ่ม "ดาวน์โหลด XML" หรือแชร์ไฟล์เข้าสู่โทรศัพท์มือถือ
  3. บนมือถือ: เปิดไฟล์ .xml หรือกดแชร์ แล้วเลือกเปิดด้วย Alight Motion
  4. โปรเจกต์จะถูก Import เข้าสู่หน้า Projects ใน Alight Motion พร้อมสำหรับปรับแต่งเอฟเฟกต์และเรนเดอร์ทันที!
